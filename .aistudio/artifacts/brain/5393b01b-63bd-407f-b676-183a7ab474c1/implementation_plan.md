# هماهنگ‌سازی نام پروژه ورکر و پیکربندی Cloudflare به ir-fury-shop

این برنامه اجرایی برای تغییر و یکپارچه‌سازی نام پروژه کلودفلر به **`ir-fury-shop`** در تمامی فایل‌های پیکربندی (`wrangler.toml`، `package.json` و اسکریپت‌های مربوطه) هم‌راستا با اتصال دیتابیس D1 تدوین شده است.

> [!IMPORTANT]
> **تصمیمات تایید شده توسط کاربر:**
> 1. **نام پروژه در `wrangler.toml`**: از `furyshop-worker` به `ir-fury-shop` تغییر می‌یابد تا مستقیماً با سرویس ورکر مد نظر شما در کلودفلر منطبق شود.
> 2. **نام در `package.json`**: به صورت هماهنگ به `ir-fury-shop` تغییر می‌یابد.
> 3. **هویت و متغیر فروشگاه**: متغیر `STORE_NAME = "FURY_SHOP"` در تنظیمات ورکر حفظ می‌شود تا هویت بصری و برند فروشگاه دست‌نخورده بماند.
> 4. **دیتابیس D1**: اتصال دیتابیس با شناسه `e3f06738-f002-4889-89a9-7736d45e8463` و نام `ir-fury-shop-db` بدون تغییر حفظ و متصل است.

---

### ۱. نمای کلی و هدف تغییرات

با تغییر نام ورکر به `ir-fury-shop`، دستورات `wrangler deploy` کلودفلر مستقیماً روی ورکر درست دیپلوی شده و ناسازگاری یا ایجاد ورکر جداگانه تحت نام‌های متفرقه از بین می‌رود. همچنین پکیج و فایل‌های پیکربندی هماهنگ خواهند شد.

---

### ۲. دیاگرام ساختار و ارتباطات پروژه

```
┌─────────────────────────────────────────────────────────────┐

├──────────────────────────────┬──────────────────────────────┤
│       پیکربندی‌ها            │       اجرای برنامه           │

│  package.json                │  Cloudflare D1 Database      │
│  ├── name: "ir-fury-shop"    │  └── ID: e3f06738-f002...    │
│  └── deploy: "wrangler deploy"                              │
└──────────────────────────────┴──────────────────────────────┘
```

### ۳. مراحل دقیق پیاده‌سازی

1. **به‌روزرسانی `wrangler.toml`**:
   - تنظیم `name = "ir-fury-shop"`.
   - بررسی و ابقای `database_name = "ir-fury-shop-db"` و `database_id = "e3f06738-f002-4889-89a9-7736d45e8463"`.
   - ابقای `STORE_NAME = "FURY_SHOP"`.

2. **به‌روزرسانی `package.json`**:
   - تغییر فیلد `"name": "react-example"` به `"name": "ir-fury-shop"`.
   - بررسی اسکریپت `deploy:worker` و `db:init` برای اطمینان از انطباق نام دیتابیس `ir-fury-shop-db`.

3. **اعتبارسنجی و تست**:
   - تست استقرار Dry-Run با دستور `npx wrangler deploy --dry-run` جهت تضمین عدم بروز خطا.
   - اجرای `npm run build` و `compile_applet` برای اطمینان از صحت کامل بیلد و پایداری کلاینت و ورکر.
